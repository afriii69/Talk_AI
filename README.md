## ⚡ Fitur Utama
- 🔒 **Akses** : Mendapatkan akses ke GPT melalui browser anda di localhost:6969.
- 💬 **Chat**  : Chat gpt sepuasnya melalui terminal. Bisa di sebut API gratis.
- 📂 **Backup**: Setiap chat akan di store di chat.txt bisa kamu gunakan untuk merespon dengan bahasa code lain dengan pembacaan txt
- 🎙️ **Mic**   : Bicara lah dengan AI menggunakan Mic mu
- 🗣️ **Speak** : Dengarkan AI mu berbicara sesuai respon pembicaraan mu


## 💽 Instalasi
#### PART 1 - Install Node js & Python [Win]
```bash
$ winget install -e --id CoreyButler.NVMforWindows
$ nvm install lts
$ nvm use lts
$ node -v      # Check jika node sudah terinstall. output contoh: 22.2.0
$ npm -v       # Check jika npm sudah terinstall. output contoh: 10.7.0
```
atau bisa langsung install di sini [NODE JS](https://nodejs.org/en/download) 
download juga Python3 di sini [PYTHON3](https://www.python.org/downloads/windows/)<br><br>


#### PART 2 - Download SC
```bash
$ git clone https://github.com/afriii69/Talk_AI.git
$ cd Talk_AI
```
jika sudah di clone, bakal ada folder bernama Talk_AI. Gunakan Git untuk clone <br><br>


#### PART 3 - Install modul dan Jalankan SC
```bash
$ npm install
$ npm run go_ai
```
<br><br>

#### PART 4  - Cara Menggunakan
```bash
$ [🔲] Press "SPACE" for speaking...
$ saat terminal menampilkan pesan di atas, harap tekan space dan pastikan mic tersambung
```
